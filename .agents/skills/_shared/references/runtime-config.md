# Runtime Config Reference Index

This compatibility index replaces the former monolithic runtime contract. Skills should load only the references needed for their current workflow:

- Language selection: `language-config.md`
- Safe config writes and stable fields: `config-mutation.md`
- Review gates and approval resume: `fix-mode.md`
- Additional skill path compatibility: `additional-skills.md`

Do not load every contract by default. Existing external references to `runtime-config.md` remain valid through this index, but canonical MACCA skills should point to the narrower file directly.
